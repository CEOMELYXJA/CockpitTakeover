# Cockpit Takeover

[Cockpit Takeover](https://ceomelyxja.github.io/CockpitTakeover/) est une carte orbitale pour tout ce que vous voulez garder en vue : un appel, une commission, une activité, une rencontre, un problème, un projet, une échéance ou un objectif personnel.

## Créer des planètes

Dans **Planètes**, donnez un nom à chaque élément, ajoutez le contexte utile et choisissez une date et une heure d’échéance. Vous pouvez aussi régler sa couleur, sa taille et ses anneaux. Les catégories ne sont pas imposées; le repère est facultatif. Les listes `.txt`, `.md` et `.json` peuvent être importées, puis précisées sur le site.

Quand vous mettez une planète en orbite, elle tourne autour du noyau. À mesure que l’échéance approche, elle se rapproche et son mouvement devient légèrement plus pressant. À l’échéance, elle rejoint le noyau; elle reste ouverte sur le site jusqu’à ce que vous la terminiez ou la replanifiiez.

## Ajuster la carte

Dans **Réglages**, ajustez le nombre de planètes visibles, l’échelle, la vitesse, les orbites magnétiques, les petites étoiles et la quantité de micro-constellations lentes. Les préférences sont enregistrées dans ce navigateur. Le fond noir et les couleurs vives s’inspirent du cockpit original.

Pour déplacer le noyau dans le widget Windows, maintenez le clic droit dessus et faites-le glisser. Les autres éléments ne captent pas les clics; les icônes Windows restent accessibles.

## Le site et le widget Windows

- Le site sert à créer et modifier la carte.
- Le widget affiche une copie transparente de cette carte sur le Bureau et continue son mouvement en arrière-plan.
- Cliquez sur **Synchroniser le widget** après vos modifications. Si le widget est ouvert, il récupère automatiquement la copie depuis **Téléchargements**.
- La copie de la carte reste locale à votre ordinateur; vos éléments personnels ne sont pas publiés sur GitHub.

Téléchargez l’application depuis les [versions Windows](https://github.com/CEOMELYXJA/CockpitTakeover/releases/latest). Le widget garde la dernière copie reçue après fermeture. Une nouvelle version de l’application met à jour le dessin et les fonctions; une nouvelle synchronisation transmet les changements de votre carte.
