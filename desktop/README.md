# Widget Windows Cockpit Takeover

## Installer le widget

1. Téléchargez l’installateur Windows depuis les [versions Cockpit Takeover](https://github.com/CEOMELYXJA/CockpitTakeover/releases/latest) et enregistrez-le dans **Téléchargements**.
2. Double-cliquez sur l’installateur. Il crée un seul raccourci **DumbFuckCockpit Widget** sur le Bureau et lance le widget.
3. Le widget apparaît sur vos écrans derrière les icônes. Vous pouvez fermer le site après avoir synchronisé vos rappels.

L’application installe ses fichiers dans le dossier Windows prévu pour les applications. Elle ne crée pas de dossier **Trinity** ni de dossier de fonctionnement sur le Bureau.

## Site et widget

- Le [site Cockpit Takeover](https://ceomelyxja.github.io/CockpitTakeover/) sert à créer des rappels précis, les associer aux sujets et choisir couleurs, tailles et apparence.
- Le widget est une scène transparente et animée sur le bureau. Il ne montre que les planètes et les étoiles, sans noms ni jauges.
- Pour mettre les changements dans le widget, cliquez sur **Synchroniser le widget** dans le site. Le fichier va dans **Téléchargements**; l’application le détecte automatiquement et garde sa dernière copie localement.
- Vous n’avez pas besoin de laisser le site ouvert. La liste de rappels et les réglages personnels ne sont pas publiés sur GitHub.

## Utiliser la carte

Un rappel démarré devient une planète de la couleur de son sujet. À mesure que son délai s’écoule, elle orbite plus près du centre. Juste avant la fin, sa pulsation s’accentue légèrement; elle rejoint ensuite le centre et disparaît du widget. Elle reste toutefois ouverte dans le site jusqu’à ce que vous la terminiez. Un clic gauche sur le centre dans le site affiche les détails de tous les rappels.

Sur le Bureau, maintenez le clic droit sur la planète centrale et déplacez-la. La carte entière suit avec douceur. Les autres planètes ne prennent pas les clics; les icônes Windows restent au premier plan.

Dans **Apparence** sur le site, choisissez combien de rappels tournent à la fois, leur taille générale, leur vitesse, les orbites et le nombre de mini étoiles blanches. Dans **Sujets**, choisissez la couleur, la taille, la description et le délai proposé pour chaque catégorie personnelle. Le site conserve vos choix dans le navigateur.

Le panneau Windows conserve l’opacité, l’animation fluide ou réduite, l’affichage sur le Bureau et le démarrage avec Windows. Il affiche aussi l’état de synchronisation et permet de recentrer le centre. Ses réglages restent enregistrés après fermeture.

## Mise à jour

Installez la nouvelle version Windows pour mettre à jour le widget. L’application conserve ses réglages et la dernière synchronisation locale.

Compatible avec Windows 10 et Windows 11. L’installateur n’est pas signé; Windows peut afficher un avertissement d’éditeur non vérifié.
