# Cockpit Takeover Widget 0.11.9

- Le centre de la planète principale suit directement le curseur pendant le glissement au clic droit.
- Le menu Windows permet de choisir l’écran gauche, l’écran droit ou les deux écrans; la position est calculée dans la zone réellement sélectionnée.
- Les micro-constellations sont plus nombreuses et un peu plus grandes; leur quantité, leur taille et leur vitesse se règlent dans l’application.
- Le panneau mobile a un bouton permanent pour se replier et se rouvrir; le logo est masqué sur petit écran.
